Weather Display

Current weather, a 3-day and hourly forecast, and an animated rain radar on a round AMOLED screen, for the Waveshare ESP32-S3-Touch-AMOLED-1.75. Install it straight from this page.

Install the firmware

Beta builds are release candidates for testing the next version and may have bugs. You can go back to Stable at any time the same way (leave Erase device unticked).
Your browser can't talk to USB devices. Use Chrome or Edge on a computer. This page must be opened over HTTPS (or on localhost) to flash.

Steps

  1. Plug the board into this computer with a USB-C data cable.
  2. Click Connect & install and pick the port named USB JTAG/serial debug unit (or the COM port that appears when you plug it in).
  3. First install: tick Erase device. Updating: leave it unticked to keep your Wi-Fi and settings.
  4. When it's done the display restarts and shows a Wi-Fi setup QR code. Scan it with your phone: it joins the display's Weather-Setup network and the setup page opens by itself. Pick your home Wi-Fi.
  5. Set your location later: long-press the weather screen for the settings QR code.

Using it

  • Tap a forecast day for its hourly view; drag sideways for other days.
  • Swipe left for the radar; tap to animate the last 3 hours, swipe down/up to zoom.
  • Long-press for the settings page (location, Wi-Fi, screen dimming).
  • The microphones dim the screen when the room is quiet and wake it on sustained sound.

If it doesn't connect

  • No port listed: try another cable or USB port; some cables only charge.
  • Still nothing: hold BOOT, tap RESET, release BOOT, then try again.
  • Close other programs using the port (serial monitors, the flash helper).
  • After flashing in BOOT mode, tap RESET once to start the firmware.

The rain radar uses Environment Canada data, so it covers Canada and the northern US border region.
